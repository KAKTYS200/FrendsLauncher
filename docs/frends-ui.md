Поведение:
- Список версий **всегда виден** и содержит все версии Minecraft (снапшоты, релизы, старые беты), с поиском и колонками «Версия / Выпущено / Тип».
- «Только релизы» — фильтр списка по типу `release`.
- «Быстрый выбор» — 15 последних релизов, короткий путь к самой свежей версии.
- Название подставляется автоматически по выбранной версии, пока пользователь не начал печатать сам.
- «Создать сборку» активна, как только выбрана версия (имя берётся из неё).
- «Тип загрузчика» — Vanilla / Forge / NeoForge / Fabric / Quilt / LiteLoader. Для Vanilla «Версия загрузчика» = «Не требуется».
- При выборе загрузчика под основным списком появляется второй список — версии загрузчика для выбранной версии игры.
- чекбоксы по умолчанию включены; «Использовать настройки лаунчера» — если снять, открывается поле памяти (мин. 512 МБ … макс. по системе).
- Типы версий переведены: релиз / снапшот / старая бета / альфа.

Цвета — палитра лаунчера: текст `#585858`, вторичный `#ACACAC`, CTA `#F9D900`, вторичная кнопка — серый градиент modena с рамкой `#B9B9B9` и радиусом 4 px.

### 7.1. Что взято из разбора `TLauncher.exe`

Разбор стартера (`TLauncher_analysis_RU.md`) подтверждает несколько решений интерфейса:

- **Масштаб.** Оригинал запускает JVM с `-Dsun.java2d.uiScale.enabled=false`, то есть отключает системное
  авто-масштабирование и считает метрики сам. `FrendsScale` делает то же самое для Qt-темы: коэффициент
  = пользовательский ползунок × высота окна.
- **Серверы.** В `InnerStateServer-1.3.json` у партнёрских серверов стоит `"hideAddress": true` — адрес
  скрыт, размещение платное. В `FrendsServersPage` адреса показываются всегда и список не сортируется за деньги.
- **Приватность.** В `tlauncher-2.0.properties` лежат `client`, `sending.tlauncher.unique`, `gpu.info`,
  `process.info`, `operating.system.info` — отпечаток машины плюс два постоянных ID. Раздел «Приватность»
  показывает ровно этот набор локально и ничего не отправляет.
- **Реклама.** Флаги `gui.notice.ad_other`, `gui.notice.ad_server`, `gui.notice.ad_youtube` и офферы
  (`installedOffers.json`) в Frends Launcher не воспроизводятся: рекламных блоков и PPI-офферов нет.
